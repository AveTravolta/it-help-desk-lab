# Week 4 Reflection – Microsoft 365 & Cloud Identity Administration

Week 4 was a major step forward in my IT learning because I moved beyond my Windows Server and Active Directory lab and began working with Microsoft 365 cloud administration. This week helped connect many of the concepts I had already learned in my on-premises environment to how they are handled in a modern cloud-based organization.

### What I Learned

This week focused heavily on the **Microsoft 365 Admin Center, Microsoft Entra ID, and Exchange Online**. I learned how administrators manage users, licenses, groups, passwords, MFA, mailboxes, aliases, distribution groups, and shared mailboxes in Microsoft 365.

I also gained hands-on experience working through realistic help desk scenarios, including:

* Resetting user passwords and troubleshooting account access
* Assigning Microsoft 365 licenses
* Managing users and groups in Microsoft Entra ID
* Investigating Microsoft Teams access issues
* Creating and managing mailboxes
* Creating distribution groups and shared mailboxes
* Managing mailbox permissions, including Send As access
* Troubleshooting common Microsoft 365 user issues
* Documenting tickets and approaching problems using a structured help desk process

### Connecting On-Premises and Cloud Administration

One of the biggest takeaways from this week was seeing how much of my previous Active Directory experience transfers into cloud administration.

Earlier in the roadmap, I worked with **Active Directory, organizational units, security groups, Group Policy, DNS, DHCP, user accounts, file shares, printers, and PowerShell**. This week showed me the cloud equivalent of many of those responsibilities through Microsoft Entra ID and Microsoft 365.

Instead of only thinking about managing computers and users inside a Windows domain, I am now learning how IT administrators manage identities, applications, email, licenses, and access across cloud services.

### Help Desk Experience

The Microsoft 365 tickets were especially valuable because they required me to think like an IT support technician rather than simply follow a tutorial.

For each issue, I practiced identifying the likely cause, checking the appropriate administrative portal, making the necessary change, and verifying that the problem was resolved.

This reinforced an important lesson from the roadmap: **IT support is not just about knowing where a setting is. It is about troubleshooting systematically and understanding why the setting affects the user.**

### Week 4 Reflection

Week 4 gave me a much better understanding of what modern IT support and cloud administration actually look like. I now have hands-on experience with both an on-premises Windows Server environment and a Microsoft 365 cloud environment.

I also feel more comfortable describing my experience as **Help Desk / IT Support with exposure to Microsoft 365, Entra ID, Exchange Online, and Active Directory administration**.

The biggest accomplishment this week was not simply learning several new Microsoft 365 tools. It was learning how these tools fit together as part of an actual IT support environment.

### Looking Ahead

With Microsoft 365, Entra ID, and Exchange Online now added to my lab experience, I am ready to continue building toward more advanced IT administration skills.

The next stage of my roadmap will continue expanding my troubleshooting and enterprise IT knowledge while preparing me for technologies and tools commonly used in real-world IT support environments.
