# 🎫 ServiceNow Ticket 01 — Windows Login Issue

**Incident:** INC0010001  
**Category:** Password Reset  
**Channel:** Phone  
**Priority:** 4 - Low  
**State:** Resolved

---

## 📝 User Issue

User reported being unable to log into their Windows computer and stated that the system reported the account or password was incorrect.

---

## 🔍 Troubleshooting

- Reviewed the user's reported login issue.
- User confirmed their password had recently been changed.
- Determined that the user was attempting to sign in using an outdated password.
- Advised the user to use their current password.

---

## 🔧 Resolution

User was able to authenticate successfully after using the current password.

**Resolution Code:** Solved (Permanently)

### Resolution Notes

> User was using an outdated password following a recent password change. Advised user to sign in using the current password. User successfully authenticated.

---

## 💡 What I Learned

This ticket introduced the basic ServiceNow incident workflow:

1. Create an incident
2. Document the user's issue
3. Set impact and urgency
4. Allow ServiceNow to calculate priority
5. Add work notes
6. Resolve the incident
7. Document the resolution

ServiceNow serves as the ticketing and documentation system, while the actual technical troubleshooting may be performed using tools such as Active Directory.
