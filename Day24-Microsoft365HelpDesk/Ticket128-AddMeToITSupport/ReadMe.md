## Ticket #128 — Add Me to IT Support

### Issue

John requested access to the IT Support resources.

### Investigation

- Verified that John needed to be added to the Oslo Support Project group
- Confirmed that the group is a security group
- Checked the current group membership
- Confirmed that John was not currently a member
- Verified that Michael was the owner of the group
- Determined that membership in the group provides access to the IT Support shared mailbox
- Confirmed the requested access with Michael

### Root Cause

John was not a member of the Oslo Support Project security group, which was required for access to the IT Support shared mailbox.

### Resolution

- Confirmed authorization with the group owner
- Added John to the Oslo Support Project security group

### Verification

- Confirmed that John was now a member of the security group
- Confirmed that the group membership would provide access to the IT Support shared mailbox
