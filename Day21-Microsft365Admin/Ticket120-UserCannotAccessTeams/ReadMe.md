# 🎫 Ticket #120 — User Cannot Access Microsoft Teams

### 📝 Issue

**User:** John Smith — HR

User reported:

> “I can't access Microsoft Teams. I was told I should have access.”

### 🔎 Investigation

* Located the user account for John Smith and verified the account was active.
* Verified the user had the appropriate Microsoft 365 license assigned.
* Reviewed **Apps and Services** to confirm which Microsoft 365 services were available to the user.
* Confirmed **Microsoft 365 Business Standard** was assigned.
* Confirmed **Microsoft Teams** was enabled.
* Checked **Microsoft 365 Service Health** and confirmed there were no active Teams service issues.

### 🔧 Troubleshooting & Resolution

* Contacted the user to clarify the reported issue.
* User reported that Teams opened briefly and then closed without displaying an error.
* User confirmed that Outlook and OneDrive were functioning normally.
* Had the user access Teams through the Microsoft 365 web interface to determine whether the issue was related to the account/service or the desktop application.
* Teams worked successfully through the web interface, indicating the Microsoft 365 account and Teams service were functioning correctly.
* Had the user restart their computer and launch the Teams desktop application again.
* User confirmed that Microsoft Teams opened and functioned normally after the restart.

### 🧠 Root Cause

**Temporary Teams desktop application/client issue.**

The exact underlying cause could not be determined, but restarting the user's computer resolved the issue.

### ✅ Verification

* User successfully opened the Teams desktop application after restarting the computer.
* User confirmed Teams was functioning normally.
* Ticket resolved and closed.
