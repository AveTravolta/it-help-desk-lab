## Ticket #130 — New Employee Needs Mailbox

### Issue

A new employee needed a Microsoft 365 account and mailbox.

### Investigation

- Verified that the employee was new and required a Microsoft 365 account
- Confirmed that the employee needed access to Microsoft 365 applications and email

### Root Cause

The new employee had not yet been provisioned with a Microsoft 365 license and account access.

### Resolution

- Assigned the required Microsoft 365 license
- Enabled access to the required Microsoft 365 applications
- Provided the employee with a temporary password
- Had the employee sign in for the first time

### Verification

- Employee successfully signed into Microsoft 365
- Confirmed that the employee had access to the required applications
- Confirmed that the mailbox was available
- Issue resolved successfully
