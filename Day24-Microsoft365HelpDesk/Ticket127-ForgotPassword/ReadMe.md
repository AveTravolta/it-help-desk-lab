## Ticket #127 — I Forgot My Password

### Issue

Emily reported that she was unable to sign in because she had forgotten her password.

### Investigation

- Looked up Emily's user account
- Verified Emily's identity
- Checked the account for blocked access or other restrictions
- Confirmed that there were no account restrictions preventing sign-in
- Asked Emily whether the issue was caused by a forgotten password or an incorrect password entry
- Emily confirmed that she had forgotten her password

### Root Cause

User forgot her Microsoft 365 account password.

### Resolution

- Reset Emily's Microsoft 365 password
- Provided the new temporary password to the user

### Verification

- Confirmed that the password reset completed successfully
- User was able to use the new password to access the account
